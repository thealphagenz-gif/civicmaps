ABOUT CIVICMAP

Making neighbourhood problems easier to see and track.

CivicMap Mumbai is an academic civic infrastructure mapping platform designed to connect citizens, neighbourhood issues and responsible authorities.

OUR PURPOSE

Turning local problems into visible civic records.

Everyday problems such as potholes, garbage, broken streetlights, drainage issues and damaged footpaths can affect an entire neighbourhood.

CivicMap provides a structured way for citizens to record these issues with a location, description and supporting evidence.

The aim is to make civic problems easier to document, organize and track.

THE IDEA

See it. Report it. Track it.

Civic participation becomes easier when people can clearly identify a problem, record where it happened and follow what happens next.

HOW IT WORKS

A simple civic reporting workflow

CivicMap follows a straightforward process.

01

Locate

Select the location of the civic problem directly on the interactive map.

02

Report

Add the issue title, description, category, authority and optional photographs.

03

Track

Keep the generated complaint reference number and follow its status.

04

Verify

Resolution information and evidence can be added to show what happened after reporting.

PLATFORM FEATURES

What CivicMap provides

📍

📸

Attach photographs to provide additional evidence for a reported issue.

🔎

TECHNOLOGY

Built as a practical academic project.

CivicMap uses a web-based frontend together with a Python backend and SQLite database.

HTML CSS JavaScript Leaflet FastAPI Python SQLite
PROJECT SCOPE

Academic prototype

CivicMap Mumbai is developed as a college project to demonstrate how a civic issue reporting platform can work.

Some future features, such as official government-system integration, authentication, moderation and large-scale deployment would require additional backend infrastructure.
